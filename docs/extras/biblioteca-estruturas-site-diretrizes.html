Biblioteca de ambientes

Este arquivo é uma página-laboratório para testar e copiar estruturas úteis nos capítulos do livro. Cada seção mostra o código e o resultado renderizado correspondente.

NotaUso recomendado

Coloque este arquivo em extras/ ou capitulos/apoio/ e inclua-o temporariamente em _quarto.yml durante a produção do livro. Depois de consolidar os padrões, use-o como referência editorial.

Premissas adotadas

Esta versão segue três decisões estruturais:

  1. cada página deve trabalhar uma ideia principal;
  2. cada bloco visual deve ter função cognitiva clara;
  3. applets e figuras devem orientar a atenção, não competir com a explicação.

7. Erro comum com correção explícita

  • Código
  • Resultado
::: {.callout-warning title="Erro comum" appearance="simple"}
**Erro.** Em $f(x)=2x+5$, dizer que a inclinação é $5$.

**Correção.** A inclinação é controlada por $2$, pois ele multiplica o $x$. O número $5$ indica onde a reta corta o eixo vertical.

**Como verificar.** Compare $f(0)=5$ e $f(1)=7$: quando $x$ aumenta uma unidade, $f(x)$ aumenta duas unidades.
:::

13. Definição, proposição e prova compacta

  • Código
  • Resultado
::: {#def-coeficiente-angular}
O **coeficiente angular** de uma reta não vertical é o número que mede a variação vertical da reta para cada unidade de variação horizontal.
:::

::: {#prp-afim-crescente}
Se $a>0$, então a função afim $f(x)=ax+b$ é crescente.
:::

::: {.proof}
Se $x_2>x_1$, então $x_2-x_1>0$. Como $a>0$, temos $a(x_2-x_1)>0$. Logo,

$$
f(x_2)-f(x_1)=a(x_2-x_1)>0.
$$

Portanto, $f(x_2)>f(x_1)$.
:::

Definição 1 O coeficiente angular de uma reta não vertical é o número que mede a variação vertical da reta para cada unidade de variação horizontal.

Proposição 1 Se \(a>0\), então a função afim \(f(x)=ax+b\) é crescente.

Demonstração. Se \(x_2>x_1\), então \(x_2-x_1>0\). Como \(a>0\), temos \(a(x_2-x_1)>0\). Logo,

\[ f(x_2)-f(x_1)=a(x_2-x_1)>0. \]

Portanto, \(f(x_2)>f(x_1)\).

**Objetivo.** Reconhecer o papel dos parâmetros $a$ e $b$ em $f(x)=ax+b$.
:::

## Antes de começar

::: {.bloco-pre-requisitos}
- Coordenadas no plano.
- Substituição numérica.
- Leitura de gráficos simples.
:::

## Ideia central

::: {.callout-note title="Ideia central" appearance="simple"}
O parâmetro $a$ controla a inclinação, e o parâmetro $b$ controla o ponto em que a reta corta o eixo vertical.
:::

  5. Verifique a leitura em tela estreita.
  6. Execute quarto preview ou quarto render.
